# Adriana Mendes — Natal 2026 | Demonstração GitHub Pages

Versão estática para apresentação ao cliente. Não usa banco de dados: as alterações do administrativo ficam no `localStorage` do navegador em que a demonstração estiver sendo usada.

## Publicar no GitHub Pages

1. Envie todo o conteúdo desta pasta para um repositório.
2. Em **Settings > Pages**, publique a branch `main` pela raiz (`/`).
3. Abra `index.html` pela URL do GitHub Pages.
